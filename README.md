# Dynamic Island для Windows

Остров в духе iPhone у верхнего края экрана: показывает, что играет, громкость, таймер и системные события, а по клику раскрывается в плеер.

Написан на WPF (.NET 8) без сторонних пакетов — только Windows API.

## Что умеет

- **Музыка.** Обложка, название и эквалайзер для любого приложения с системной медиасессией (Spotify, браузер, Яндекс Музыка…). Цвет полосок берётся из обложки, и в тот же цвет окрашивается светлый ободок острова. При смене трека новая обложка выталкивает старую — влево для следующего трека, вправо для предыдущего.
- **Текст песни.** Синхронные строки с [LRCLIB](https://lrclib.net) прямо в компактном острове; он растягивается под длину строки.
- **Плеер.** По клику — большая обложка, перемотка, «назад / пауза / вперёд» и подсветка в цветах обложки, которая движется под звук. Если у трека есть текст, плеер становится выше и показывает три строки: та, что поётся, стоит посередине и заливается светом слева направо, соседние — меньше и не в фокусе.
- **Живой спектр.** Полоски считаются по реальному выводу звука (WASAPI loopback), а не случайно.
- **Громкость.** Индикатор при изменении громкости; колесо мыши над островом её меняет. На 0 и 100% полоска тянется дальше, как резинка, и возвращается.
- **Таймер.** От 1 до 99 минут. Пока играет музыка, таймер отделяется в отдельный «пузырь» рядом — вытягивается из острова, как капля. Последние 10 секунд отсчёт краснеет и пульсирует. По окончании звонит, пока не кликнете.
- **Заряд наушников.** Процент заряда Bluetooth-наушников — в раскрытом острове и в плеере, при подключении и отдельным предупреждением на 20% и 10%. Показывается для устройств, которые сообщают заряд Windows (тот же процент, что в «Параметрах»).
- **Уведомления.** Подключение зарядки, смена аудиоустройства (наушники, Bluetooth), Wi-Fi / Ethernet, включение и отключение VPN.
- **Не мешает.** Прячется, когда на весь экран открыта игра или видео, не появляется в Alt-Tab и не забирает фокус.
- **Настройки.** Текст песен, эффекты его строк в плеере (заливка, размер и размытие соседних), ободок в цвет обложки, уведомления о сети, скрытие на полном экране и автозапуск выключаются на странице «Настройки» в меню.

## Управление

| Действие | Результат |
| --- | --- |
| Клик | Раскрыть плеер или таймер, повторный клик — свернуть |
| Клик по обложке в плеере | Открыть приложение, в котором играет музыка |
| Правый клик | Меню: таймер, настройки, закрыть остров; со страницы настроек — назад в меню |
| Клик колесом | Спрятать остров на 5 секунд |
| Колесо мыши | Громкость (в настройке таймера — минуты) |
| Клик по звонящему таймеру | Выключить звонок |

## Скачать

Готовый `DynamicIsland.exe` лежит в [релизах](https://github.com/mihailkotovski/DynamicIsland/releases/latest). Устанавливать ничего не нужно: скачайте и запустите. Подходит для 64-битных Windows 10 2004 (сборка 19041) и новее, Windows 11.

Файл не подписан, поэтому при первом запуске SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
git clone https://github.com/mihailkotovski/DynamicIsland.git
cd DynamicIsland
dotnet run -c Release
```

Один exe-файл, которому не нужен установленный .NET — так же собирается релиз:

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```

### Выпуск новой версии

Релиз собирает GitHub Actions ([release.yml](.github/workflows/release.yml)) — достаточно запушить тег:

```bash
git tag v1.1.0
git push origin v1.1.0
```

### Шрифты

Остров рисуется шрифтом SF Pro: файлы лежат в [Fonts](Fonts/) и встраиваются в exe при сборке. Шрифт принадлежит Apple и распространяется на условиях её лицензии. Без этих файлов используется Segoe UI.

## Отладка

```bash
DynamicIsland.exe --view MediaBig
DynamicIsland.exe --timer 90
```

`--view` закрепляет одно состояние острова (`Idle`, `Media`, `Timer`, `Volume`, `Charge`, `Toast`, `Notice`, `MediaBig`, `IdleBig`, `TimerBig`, `TimerSet`, `Menu`, `Settings`), `--timer` сразу запускает отсчёт на указанное число секунд.

Необработанные ошибки пишутся в `%TEMP%\DynamicIsland.log`.

## Как устроено

| Файл | За что отвечает |
| --- | --- |
| `MainWindow.xaml(.cs)` | Все состояния острова, переходы между ними, указатель |
| `Spring.cs` | Пружина, на которой построено каждое движение |
| `Goo.cs` | Чёрное тело острова: пилюля, пузырь и перемычка, которая тянется между ними и рвётся |
| `Icon.cs` | Собственные иконки: громкость, наушники, сеть, VPN, таймер |
| `MediaService.cs` | Текущий трек через системную медиасессию (GSMTC), цвет из обложки |
| `Cover.cs` | Обложка: новая выталкивает старую в сторону, куда листается плейлист |
| `SourceApp.cs` | Переход к окну приложения, в котором играет музыка |
| `LyricsService.cs` | Поиск и разбор синхронного текста с LRCLIB |
| `Lyric.cs` | Строка текста в плеере, которая заливается светом, пока её поют |
| `Spectrum.cs` | Захват вывода звука и разложение по частотам |
| `Equalizer.cs`, `Aura.cs` | Полоски и подсветка плеера |
| `AudioService.cs` | Громкость и смена устройства вывода (Core Audio) |
| `Headset.cs` | Заряд Bluetooth-наушников |
| `NetworkService.cs` | Состояние сети и VPN |
| `Timer.cs`, `Ring.cs`, `Digits.cs` | Отсчёт, звонок, кольцо и перелистывание цифр |
| `Settings.cs`, `Toggle.cs` | Настройки из меню и их переключатель |
| `Native.cs` | Win32: поверх всех окон, полноэкранный режим, батарея, автозапуск, клавиши громкости и треков |

## Конфиденциальность

Единственный сетевой запрос — поиск текста на `lrclib.net`: туда уходят название трека и исполнитель. Больше приложение ничего никуда не отправляет. Если выключить «Текст песен» в меню, не будет и этого запроса.

Автозапуск включается записью в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и выключается тем же переключателем. Остальные переключатели меню хранятся в `HKCU\Software\DynamicIsland`.
