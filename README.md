# Dynamic Island для Windows

Остров в духе iPhone у верхнего края экрана: показывает, что играет, громкость, таймер и системные события, а по клику раскрывается в плеер.

Написан на WPF (.NET 8) без сторонних пакетов — только Windows API.

## Что умеет

- **Музыка.** Обложка, название и эквалайзер для любого приложения с системной медиасессией (Spotify, браузер, Яндекс Музыка…). Цвет полосок берётся из обложки.
- **Текст песни.** Синхронные строки с [LRCLIB](https://lrclib.net) прямо в компактном острове; он растягивается под длину строки.
- **Плеер.** По клику — большая обложка, перемотка, «назад / пауза / вперёд» и подсветка, которая движется под звук.
- **Живой спектр.** Полоски считаются по реальному выводу звука (WASAPI loopback), а не случайно.
- **Громкость.** Индикатор при изменении громкости; колесо мыши над островом её меняет.
- **Таймер.** От 1 до 99 минут. Пока играет музыка, таймер отделяется в отдельный «пузырь» рядом. По окончании звонит, пока не кликнете.
- **Уведомления.** Подключение зарядки, смена аудиоустройства (наушники, Bluetooth), Wi-Fi / Ethernet, включение и отключение VPN.
- **Не мешает.** Прячется, когда на весь экран открыта игра или видео, не появляется в Alt-Tab и не забирает фокус.

## Управление

| Действие | Результат |
| --- | --- |
| Клик | Раскрыть плеер или таймер, повторный клик — свернуть |
| Правый клик | Меню: таймер, автозапуск с Windows, закрыть остров |
| Колесо мыши | Громкость (в настройке таймера — минуты) |
| Клик по звонящему таймеру | Выключить звонок |

## Требования

- Windows 10 2004 (сборка 19041) или новее, Windows 11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) для сборки, .NET 8 Desktop Runtime для запуска

## Сборка и запуск

```bash
git clone <адрес репозитория>
cd DynamicIsland
dotnet run -c Release
```

Один exe-файл, которому нужен только установленный .NET 8 Desktop Runtime:

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

### Шрифты

Остров рассчитан на SF Pro, но файлы шрифта в репозиторий не входят — их нельзя распространять. Без них используется Segoe UI. Как вернуть оригинальный вид, написано в [Fonts/README.md](Fonts/README.md).

## Отладка

```bash
DynamicIsland.exe --view MediaBig
DynamicIsland.exe --timer 90
```

`--view` закрепляет одно состояние острова (`Idle`, `Media`, `Timer`, `Volume`, `Charge`, `Toast`, `Notice`, `MediaBig`, `IdleBig`, `TimerBig`, `TimerSet`, `Menu`), `--timer` сразу запускает отсчёт на указанное число секунд.

Необработанные ошибки пишутся в `%TEMP%\DynamicIsland.log`.

## Как устроено

| Файл | За что отвечает |
| --- | --- |
| `MainWindow.xaml(.cs)` | Все состояния острова, переходы между ними, указатель |
| `Spring.cs` | Пружина, на которой построено каждое движение |
| `MediaService.cs` | Текущий трек через системную медиасессию (GSMTC), цвет из обложки |
| `LyricsService.cs` | Поиск и разбор синхронного текста с LRCLIB |
| `Spectrum.cs` | Захват вывода звука и разложение по частотам |
| `Equalizer.cs`, `Aura.cs` | Полоски и подсветка плеера |
| `AudioService.cs` | Громкость и смена устройства вывода (Core Audio) |
| `NetworkService.cs` | Состояние сети и VPN |
| `Timer.cs`, `Ring.cs`, `Digits.cs` | Отсчёт, звонок, кольцо и перелистывание цифр |
| `Native.cs` | Win32: поверх всех окон, полноэкранный режим, батарея, автозапуск |

## Конфиденциальность

Единственный сетевой запрос — поиск текста на `lrclib.net`: туда уходят название трека и исполнитель. Больше приложение ничего никуда не отправляет.

Автозапуск включается записью в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и выключается тем же переключателем.
